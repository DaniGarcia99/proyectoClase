# Sitio web de un centro de FP
---
Este sitio web es de prueba y se usara en clase de Desarrollo de interfaces web.
Consiste en un sitio web para un centro formativo de fp.

## Tecnologias
- Frontend
    - HTML5 (moderno)
    - CSS3
    - Vanilla JavaScript
- Backend
    - Node.js
    - Express 4.22.3
    - Plantillas EJS

## Arquitectura
- Todo en una unica pagina index, dividido por secciones.

## Contenido de la web
- El contenido debe ser realista
- El contenido debe ser en ingles
- Las imagenes por defecto seran de picsum.photos

## Convenciones del lenguaje
- Usa ingles para las variables y funciones

## Limitaciones
- No usar grid
